# header-adjuster

An Obsidian plugin for adjusting markdown header levels.

## Agent skills

### Issue tracker

Issues and PRDs live as local markdown under `.scratch/` — never published to
GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, unchanged, written as a `Status:` line in each
issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
